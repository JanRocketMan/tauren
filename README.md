# Tauren

A from-scratch learning reimplementation of [Tau](https://github.com/huggingface/tau),
the minimalist Python coding-agent harness.

The goal is not to copy Tau. The goal is to understand it by rebuilding it,
one small task at a time, using tests as the specification.

## Quick start

```bash
cd ~/tauren
uv venv --prompt tauren
uv sync
uv run pytest
```

The `--prompt tauren` flag labels the virtual environment so your shell shows
`(tauren)` instead of `(.venv)`. It works on a fresh venv and on an existing
one, and it keeps installed packages.

## How this project works

- Each task lives in `docs/task-NN.html` and opens with the commit it is
  based on
- Two commit types run the course: `task:` commits add work, `done:` commits
  implement it
- The task spec describes the concepts and the contract
- Your implementation goes in `src/`
- The tests in `tests/` tell you when you are done
- `ruff` and `mypy` keep the code clean and typed

See `docs/index.html` for the goal, scope, and roadmap.
See `AGENTS.md` for the working rules.
